## The approach

### Phase 1 — Testing (Months 1-2)

Rigorous angle testing against non-captive agents using pre-warmed inbox infra plus Claude Code driven automation. Goal is to find the winning combination of ICP slice, offer, and copy before we spend a dollar on scaled infrastructure.

**What we do in Phase 1:**
- Build the target list from Google Maps scraping (my brother's team already runs this for a similar client, 3M/mo sends, untapped data not sitting in Apollo/ZoomInfo/Cognism).
- Segment by non-captive vs captive using enrichment logic. This is the manual filter LinkedIn Sales Nav alone won't catch.
- Set up 250-270 pre-warmed mailboxes ($1.50/inbox/mo). Live campaigns in 4-5 days, not 14-20.
- Redirect sender domains to your website.
- BCC main company mailbox when replies come, so leads land in your team's inbox from Day 1.
- Automate the whole sequencer flow via Claude Code + MCP. You get a seat, your team can chat with the system directly.
- Angle test in parallel: multiple audience slices, multiple copy versions, multiple offers. Claude Code lets us run tens of variations without manual click-through in Clay.

**Deliverables per week:**
- List: 3,000-5,000 verified non-captive agent contacts
- Sends: 20-30k emails
- Reply handling: routed to your team via BCC
- Report: what's converting, what's not, next test to run

### Phase 2 — Scale (Month 3+)

Once we have a winner (positive reply volume + booked meetings), transition to retainer. Move to owned domains + owned inboxes if you want, or keep pre-warmed if pace matters more than ownership. You own the infrastructure either way.

## Compliance stance

Cold email in the US is a gray area, not a black one. We don't touch GDPR-protected geographies. Standard practices: sender identity in the email, one-click unsubscribe honored, no misleading subject lines, no address harvesting. That covers CAN-SPAM. You're already in SaaS compliance thinking so we'll flex to whatever internal bar you set.

The FTC / FBI enforcement pattern you mentioned (fingerprinting, 6-12 month evidence build, 2027 fines) is worth watching. For now we stay inside the practices that the SaaS outbound community (which I'm active in) treats as safe.
